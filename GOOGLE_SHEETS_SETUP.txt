SANDMAN SERVICES — GOOGLE SHEETS SETUP

WHAT THIS VERSION DOES
- Keeps "Download Excel"
- Adds "Save to Google Sheets"
- Sends the REVIEWED/EDITED table values, not the raw AI values
- Adds one Google Sheet row per ticket
- Uses Ticket # / PRO Number to skip duplicates
- Keeps your Sandman username/password login
- Does NOT expose your Google secret in the browser

STEP 1 — CREATE THE GOOGLE SHEET
1. Go to Google Sheets.
2. Create a blank spreadsheet.
3. Name it: Sandman Ticket Log
4. You do not have to manually create headings. The Apps Script will do it.

STEP 2 — OPEN APPS SCRIPT
1. In the Google Sheet click Extensions → Apps Script.
2. Delete the sample code.
3. Open GOOGLE_APPS_SCRIPT.gs from this ZIP.
4. Copy all of it and paste into Apps Script.

STEP 3 — CREATE A SECRET
Choose one long random secret. Example:
SandmanSheets_8Kp39Vx2Lm71Qr5Nz4Tc90Aa6Wd

Do not use that exact example for a public site.

In Apps Script change:
REPLACE_WITH_YOUR_LONG_RANDOM_SECRET

to your own secret.

STEP 4 — DEPLOY APPS SCRIPT
1. Click Deploy → New deployment.
2. Click Select type → Web app.
3. Description: Sandman Ticket Receiver
4. Execute as: Me
5. Who has access: Anyone
6. Click Deploy.
7. Google may ask you to authorize the script.
8. Copy the Web App URL ending in /exec.

STEP 5 — ADD TWO NEW VERCEL ENVIRONMENT VARIABLES
Keep all your existing environment variables.

Add:

GOOGLE_SHEETS_WEBAPP_URL
Value = the Apps Script /exec URL

GOOGLE_SHEETS_SECRET
Value = the exact same secret you put in GOOGLE_APPS_SCRIPT.gs

Your environment variables should now include:
OPENAI_API_KEY
SITE_USERNAME
SITE_PASSWORD
SITE_AUTH_TOKEN
GOOGLE_SHEETS_WEBAPP_URL
GOOGLE_SHEETS_SECRET

STEP 6 — UPLOAD WEBSITE FILES
Replace/update the files in GitHub using this ZIP.

Important new file:
api/sheets.js

Also update:
index.html
api/extract.js

Keep:
api/login.js
manifest.webmanifest
sw.js
icons
vercel.json

STEP 7 — DEPLOY
Commit to GitHub.
Vercel should automatically deploy.
If required, redeploy after adding the new environment variables.

STEP 8 — TEST
1. Open Sandman website.
2. Log in.
3. Upload ONE ticket.
4. Extract.
5. Review/edit the fields.
6. Click Save to Google Sheets.
7. Open Sandman Ticket Log.
8. Confirm the row was added.
9. Click Save to Google Sheets again with the same Ticket #.
10. It should report the duplicate and NOT add another row.

IMPORTANT
- If Ticket # is blank, the row is allowed because there is no reliable duplicate key.
- Anyone who knows your Sandman website password can submit data and consume your OpenAI credits.
- The Google Sheet itself does not need to be shared publicly.
